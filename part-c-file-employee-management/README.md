# Part C: Menu-Based Employee Management System Using File Handling

This module provides a menu-driven Java application for managing employee records using file handling.

**Topics Covered:**
- Menu-driven console interface
- File I/O for persistence
- Add, Display, Delete employee operations

**Project Structure:**
- `pom.xml`: Maven module configuration
- `src/main/java/com/demo/employee/`: Main Java source files
- `src/test/java/`: Test sources

**Build Instructions:**
```bash
cd part-c-file-employee-management
mvn clean install
```
**How to run:**
Example main class: `com.demo.employee.EmployeeManagementSystem`
