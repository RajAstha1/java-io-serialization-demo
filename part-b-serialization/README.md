# Part B: Serialization and Deserialization of Student Object

This module demonstrates Java object serialization and deserialization using a Student object.

**Topics Covered:**
- Java Serialization
- File I/O
- Reading/writing objects

**Project Structure:**
- `pom.xml`: Maven module configuration
- `src/main/java/com/demo/serialization/`: Main Java source files
- `src/test/java/`: Test sources

**Build Instructions:**
```bash
cd part-b-serialization
mvn clean install
```
**How to run:**
Example main class: `com.demo.serialization.StudentDemo`
