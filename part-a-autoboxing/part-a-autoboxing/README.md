# Part A: Sum of Integers Using Autoboxing/Unboxing

This module demonstrates Java autoboxing and unboxing by calculating the sum of a list of integers.

**Topics Covered:**
- Autoboxing and unboxing
- Parsing strings to integers (`Integer.parseInt`)
- Processing integer collections

**Project Structure:**
- `pom.xml`: Maven module configuration
- `src/main/java/com/demo/autoboxing/`: Main Java source files
- `src/test/java/`: Test sources

**Build Instructions:**

```bash
# Navigate to this module folder
cd part-a-autoboxing
# Build and package
mvn clean install
```

**How to run:**

Example main class:
`com.demo.autoboxing.SumCalculator`
